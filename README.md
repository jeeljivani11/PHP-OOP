## Concepts Practiced

- Classes and Objects
- Properties and Methods
- Constructors
- Inheritance
- Parent Constructor (`parent::__construct()`)
- Encapsulation
- Private Properties
- Getter Methods
- Return Values
- Conditional Statements
- Basic Business Logic

- Product Billing – Calculating product totals and discounts.
